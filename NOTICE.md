# Origem dos recursos

- O código deste projeto foi desenvolvido por Alison Cruz.
- `plugins/usage-panel/ui/codex.webp` é o sprite original do mascote do Codex, utilizado no plugin local que deu origem ao projeto. O desenho não foi criado por este projeto.
- Coroa, balões e outros acessórios são elementos HTML/SVG da interface.
- As ilustrações e o GIF em `docs/assets/` são gerados por código e identificados como exemplos. Não representam captura de execução nem ampliam a matriz de capacidades comprovadas.
- Node.js, Codex, OpenAI e os demais nomes citados pertencem aos seus respectivos titulares. O projeto é independente.
