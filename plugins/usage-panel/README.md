# Pacote do Codex Pulse

Plugin técnico `usage-panel`, versão 0.4.1, distribuído pelo marketplace `codex-pulse`.

O título de aba preservado é **Uso restante**. A documentação de uso, instalação, imagens e limitações está no [README principal](../../README.md). Detalhes de coleta estão na [arquitetura](../../docs/architecture.md), e os testes registrados estão na [matriz de validação](../../docs/validation.md).

O host inicia o servidor por `mcp.json`. Nenhuma dependência npm da documentação é necessária para executar este pacote.
